# 轨道缺陷检测 Railway Detection USTB途安实践团2026

基于图形学与统计学的无监督轨道缺陷检测工具

## 摘要

轨道上的缺陷类别多样、可用于训练的样本稀少，却可能造成严重的安全隐患。针对这一问题，本项目提出一种基于图形学与统计学的无监督检测方案，仅需少量正常轨道图像，即可构建高灵敏度的检测模型，无需任何缺陷样本标注。

在固定光源与固定拍摄视角下，金属轨道表面会形成与轨道近乎平行的线状光泽，而缺陷会破坏光泽的亮度与形态。基于这一观察，本方案首先对图像进行几何校正，将轨道自动对齐至图像中央；随后通过 FFT 频域定向滤波剔除线状光泽纹理、保留缺陷结构；再利用正常轨道样本逐像素统计均值 μ 与标准差 σ，建立“正常轨道模型”。检测时，对待检图像逐像素计算 Z-score 异常分数，经阈值分割、形态学清理与连通域分析，最终以检测框输出缺陷位置。

本方案模型体积小、计算简单、灵敏度高，适合部署于巡检小车等边缘设备，也可作为端侧快速预筛，配合图像识别模型完成缺陷分类，兼顾召回率与准确性。

## 说明

- 本算法完全基于相机位置不变，轨道类型不变，光线条件不变的假设，且模型灵敏度极高。固模型训练所使用的所有图像，均需上车实地拍摄，摄像头更换，光源更换，小车高度调整等，均需重新采集照片建模。
